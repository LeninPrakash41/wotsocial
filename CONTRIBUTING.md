# Contributing to WotSocial

First off, thank you for considering contributing to WotSocial! 🎉 This project thrives on community feedback and contributions. Every contribution, big or small, helps make this platform better for modern creators.

## 🤝 How Can I Contribute?

### 🐛 Reporting Bugs
If you find a bug, please create an issue! Include as much detail as possible:
- Steps to reproduce the bug.
- Expected vs. actual behavior.
- Screenshots if applicable.
- OS and browser details.

### ✨ Suggesting Enhancements
Have an idea for a new feature? We'd love to hear it! Open an issue and:
- Describe your idea clearly.
- Explain how it benefits the community of creators.
- Provide a potential solution or design if you have one.

### 💻 Pull Requests
Ready to code? Awesome!
1. **Fork** the repository and clone it locally.
2. **Setup** the project using the Quick Start in `README.md`.
3. Create a **new branch** for your feature or bug fix: `git checkout -b feature/your-feature-name`.
4. Make your changes and commit them with clear, descriptive messages.
5. Push to your fork: `git push origin feature/your-feature-name`.
6. Open a **Pull Request** against the `main` branch.

### 🔰 Good First Issues
If you're new to open source or to this codebase, look for issues tagged with `good first issue`. These are specifically selected to be approachable and a great way to get started.

## 🛠 Coding Standard
- Clean, readable TypeScript.
- Tailwind CSS for all styling (no custom CSS without good reason).
- Follow existing file structure (Pages in `/src/pages/`, Reusable components in `/src/components/`, API calls in `/src/services/`).

## ❓ Need Help?
Feel free to ask questions inside issues or PRs. The core team is here to help you get your code merged!
