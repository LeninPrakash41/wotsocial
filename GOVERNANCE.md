# Project Governance

This document outlines the governance model for the SocialVase project to ensure its ongoing sustainability and a healthy community environment.

## 🤝 Project Philosophy

SocialVase is fundamentally committed to empowering creators. We strive for transparency, collaboration, and a welcoming environment for all contributors.

## 👥 Roles and Responsibilities

### Users
Anyone who uses SocialVase is a User. Users are encouraged to:
- Participate in discussions.
- Report bugs with reproducible steps.
- Suggest features or improvements.

### Contributors
Anyone who submits a patch, documentation update, or contributes code/design. Contributors are respected members of the community whose work directly improves the platform.

### Maintainers
Maintainers are individuals who have shown dedication to the project through regular, high-quality contributions and community engagement. 
**Responsibilities:**
- Reviewing and merging Pull Requests.
- Triaging issues and labeling them (e.g., `good first issue`, `bug`, `enhancement`).
- Making final decisions on architecture and roadmap.

*New maintainers can be nominated by existing maintainers based on their prolonged contribution and demonstrated understanding of the project's vision.*

## 🗣 Decision-Making Process

We prefer a **consensus-driven approach**.
1. **Discussion:** Significant changes should start with an Issue or Discussion post.
2. **Review:** Maintainers will review proposals and provide feedback. Community input is highly encouraged.
3. **Action:** Once general consensus is reached, a Pull Request can be implemented and merged. If consensus cannot be reached, the core Maintainer team will hold a vote to resolve the deadlock.

## 🚫 Code of Conduct

While we encourage passionate discussion, all participants are expected to communicate professionally and respectfully. Harassment or abusive behavior will not be tolerated and may lead to a ban from the project repository.

## 📅 Roadmap 

The roadmap is maintained via our project boards. We prioritize issues based on user feedback, technical debt reduction, and strategic alignment with our goal of being the best open-source AI social media manager.
